Summary
fix(admin): run disable matching accounts as a background job
Description
Because:

- "Disable matching accounts" scanned every account inside the request, so
  it hit the 30s gateway timeout and returned a 504.

This commit:

- Runs the scan as a background job, one at a time, with one Redis lock
  for both blocklist pages and a status key for each page.
- Scans `emails` in id ranges, filters domains in SQL, and stops at the
  first error.
- Refreshes the owner-checked lock on each progress save, and stops the
  scan when the refresh fails.
- Has the panel follow a running scan on load, poll its status, and ignore
  a second start.

Closes: FXA-15088
