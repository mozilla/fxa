Summary
perf(auth): count devices directly in recoveryKey/exists
Description
Because:
- The route fetched full device rows, Redis session tokens, and merged
  them only to take `.length`.
- The endpoint runs on every Settings load plus sign-in and reset flows.
- The old length was capped by findByUid's 500 limit; the count is not.

This commit:
- Adds Device.countByUid, a plain query with the accountDevices zombie filter.
- Adds db.deviceCount with a db.deviceCount.retrieve StatsD counter.
- Uses the count in recoveryKey/exists; response shape is unchanged.
