Summary
feat(pairing): handle v2 pairing timeouts and cancellations
Description
Because:
- A QR nobody scanned left the user on a code that had quietly expired.
- The screens that end pairing did not say why the flow ended, and did not
  guarantee the pairing channel was closed.

This commit:
- Gives up on the authority's QR after two minutes of no scan, clearing the
  timer when a device scans, when the flow fails, and on unmount.
- Passes the reason through router state so each screen shows the right variant.
- Adds a supplicant timeout and cancel container.
- Closes the pairing channel on the terminal screens, so none outlives the flow.
