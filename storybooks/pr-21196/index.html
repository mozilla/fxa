Summary
feat(settings): serve the default favicon from the CDN
Description
## Because

- The favicon loads slowly, because the app server serves it instead of the CDN.
- `packages/fxa-settings/public/index.html` declares no `<link rel="icon">`. The browser then makes an implicit `/favicon.ico` request to the app server.

## This pull request

- Adds `assets/other/favicons/mozilla-accounts.png`, a copy of the fxa-settings `favicon.png` (196x196). The "CDN Asset Upload" workflow publishes it on a merge to main.
- Adds a default icon link to `index.html`. The link points at `https://cdn.accounts.firefox.com/other/favicons/mozilla-accounts.png` and applies before the JS loads.
- Updates `Head` to render its icon link only when the `favicon` prop has a value. A CMS favicon renders a later icon link through Helmet, and the browser uses the last icon link. The CMS favicon still wins.
- Adds `packages/fxa-react/components/Head/index.test.tsx` for both `Head` cases.
