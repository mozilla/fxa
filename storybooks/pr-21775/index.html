Summary
feat(settings): add Synced data row and delete Sync data flow
Description
Because:
- Users need to delete their Sync data from Settings once per-engine toggles in Firefox stop deleting server data.
- Security review SA-1022 requires the MFA guard plus a password check before the delete.

This commit:
- Add a "Synced data" row to Data Collection and Use, shown when a device can sync, that opens the new flow.
- Add /settings/delete_sync_data: MFA guard, password reauth, then pick devices to sign out, one row per device name as in Connected Services.
- Gate the row and route on featureFlags.syncDataDeletionEnabled, a new content-server flag (off by default), and on the account having a password.
- Size UnitRow CTAs to their label up to 256px before wrapping, and pad row content before the CTA with and without Nova.
- Share the device icon with Connected Services and map isSyncCapable onto the Settings model.

Relates to FXA-14895
