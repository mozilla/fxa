Description
## Because

- The code input showed "This field is required" when the user blurred the empty field, before any submit.
- The error showed on the signin confirm, unblock, recovery code, passwordless, signup confirm, and pair TOTP pages.

## This pull request

- Removes `mode: 'onBlur'` from the `useForm` call in `FormVerifyCode`. Validation now runs on submit only.
- Adds a test that blurs the empty input and checks that no error tooltip appears.
