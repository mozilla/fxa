Summary
feat(oauth): add step-up auth telemetry
Description
Because:

* the RFC 9470 step-up path is unmeasured — nothing distinguishes it
  from an ordinary sign-in
* both rejection causes collapse into errno 170, so an unmet acr_values
  reads identically to a stale max_age
* tuning AMO's max_age needs the distribution of session auth age

This commit:

* extracts the step-up gate into a pure evaluateStepUp, observed for
  telemetry through an onStepUpEvaluated callback that can neither change
  nor block the verdict
* adds a step_up_auth Glean group — requested, satisfied, and rejected
  with a reason
* adds lib/metrics/step-up.ts, emitting oauth.step_up.* counters and an
  auth_age histogram per backend, reporting their own failures
* stashes metricsEventUid before the first Glean call so the metrics
  opt-out resolves on the unauthenticated /authorization routes

Closes #FXA-14440
