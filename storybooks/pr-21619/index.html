Description

- A pairing failure in Sentry does not say why the socket closed.
- A resumed socket leaves no trace, so resume rates are unknown.

- Tags captureException with pairing.close_reason in the pairing client.
- Sends one captureMessage for each resumed event.
- Adds optional tags and captureMessage to sentry-browser.
- Adds unit tests for each reason, the event and the tags.
