fix(auth-server): Repair two auth-server specs left broken on main
Description
Because:
* account.spec.ts still expected acceptLanguage "en-US" after en-US was
  dropped from supported-languages.json, so negotiation resolves it to "en".
* passkey_wraps.in.spec.ts imported VirtualAuthenticator from the package
  barrel, which no longer exports it, so it was undefined at runtime.

This commit:
* Updates the four acceptLanguage expectations to "en", matching the change
  already made to email-helpers.spec.ts.
* Imports VirtualAuthenticator from @fxa/accounts/passkey/testing, as
  passkeys.in.spec.ts already does.
