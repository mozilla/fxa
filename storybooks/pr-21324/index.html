chore(auth): remove /mfa/test and /mfa/test2 scaffolding routes
Description
## Because

- The `/mfa/test` and `/mfa/test2` routes were scaffolding from when we built the MFA auth strategy. They have no remaining callers.
- The `test` MFA action existed only for those routes.

## This pull request

- Removes `GET /mfa/test`, `POST /mfa/test` and `POST /mfa/test2` from `lib/routes/mfa.ts` in `fxa-auth-server`.
- Removes `test` from the default `mfa.actions` in the auth-server config.
- Removes `mfaTestGet`, `mfaTestPost` and `mfaTestPost2` from `fxa-auth-client`. This is a breaking change for those three methods only.
- Removes the `test` action from the config override in `mfa_totp.in.spec.ts`.
- Deletes `functional-tests/tests/misc/mfa.spec.ts`, which only drove the removed routes.
