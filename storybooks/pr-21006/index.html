Summary
feat(settings): Add passkey HPKE key-wrapping crypto lib
Description
Because:
* Passkey PRF-derived keys need an HPKE envelope to wrap account keys
  client-side.
* The format is frozen once the first wrap exists in production, so the
  sizes and bindings have to be pinned before anything composes them.

This commit:
* Adds packages/fxa-settings/src/lib/passkey-crypto: HPKE seal/open and
  AES-GCM key-wrap layers over hpke@1.1.3, pinned exactly.
* Stores skR as the raw scalar (Nsk 66) rather than pkcs8, left-padded
  here because the library's serialiser does not pad.
* Prefixes a module-owned domain-separation label to each layer's info
  and aad.
* Guards every fixed-width field, and requires pkR alongside the private
  key when opening.
* Adds tests against real Web Crypto, including the RFC 9180 A.6 vectors
  and a frozen envelope fixture.
