Summary
chore(admin-panel): build with webpack 5 instead of rescripts
Description
## Because

- `fxa-admin-panel` was the last package to build with `react-scripts` and `@rescripts/cli`. Both are unmaintained.
- The rescripts patch found the webpack loader by array index, so any create-react-app change broke it.
- The build needed the `--openssl-legacy-provider` flag to run on current Node versions.

## This pull request

- Adds `config/webpack.config.js`, `config/webpackDevServer.config.js` and `jest.config.js` to `fxa-admin-panel`, modeled on `fxa-settings`.
- Deletes `.rescriptsrc.js` and the shared `packages/fxa-react/configs/rescripts.js`.
- Removes the `react-scripts`, `@rescripts/cli` and `jest-watch-typeahead` dependencies.
- Declares the SVG and CSS module types in `src/react-app-env.d.ts`, which no longer references react-scripts types.
- Turns on the automatic JSX runtime. `babel-preset-react-app` defaults to the classic runtime, and most components use JSX without an import of React.
- Points the dev server websocket at port 8092. The page loads from the admin proxy on 8091, so the page origin names the wrong port.
