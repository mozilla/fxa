Summary
feat(settings): record why a pairing failed on the phone
Description
Because:

- dtm_mobile.timeout_view reported `timeout` for every supplicant failure, so a desktop that gave up could not be told from a phone that lost signal.
- The channel hash was only set on supplicant pages, so the two devices' events could not be joined.

This commit:

- Adds a `cause` extra: peer_closed, connection_lost or error. `reason` is unchanged.
- Derives the cause from how the pairing socket closed.
- Records the channel id the authority creates, so its events carry the channel hash.

Closes FXA-15085
