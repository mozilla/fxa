Summary
refactor(settings): move all hooks into lib/hooks and add a barrel
Description
Because:

* The React style guide says to move `lib/hooks.tsx` into a `hooks/` directory
  once it grows, and six hooks still sat outside that layout.
* The node style guide asks for an index.ts per folder, imported from the folder
  rather than the file; callers used a different specifier per hook.
* `useTotpSetup` reached `useMfaErrorHandler` through a component, so a barrel
  covering every hook would import `lib/hooks` back into itself.

This commit:

* Moves the last six hooks into `lib/hooks/[name]/index.*` and splits
  `lib/hooks.test.tsx` into a test beside each hook.
* Exports all 17 hooks from `lib/hooks/index.ts`, naming `useThrottle` and
  `useNavigateWithoutRerender` because `export *` skips defaults.
* Extracts `MfaContext` and `useMfaErrorHandler` out of `Settings/MfaGuard` into
  `lib/hooks/useMfaErrorHandler`.
* Points 109 files at the barrel; `src/models` keeps direct paths, as the barrel
  documents.
* Drops two dead `jest.mock('lib/hooks')` factories that mocked hooks the barrel
  never exported.

Closes: https://mozilla-hub.atlassian.net/browse/FXA-7097
