Summary
fix(admin-panel): return every account matching an email search
Description
Because:

- An address can be one account's current email and another account's
  sign-up email that was removed and later reused, for example a school
  address recycled years later.
- Search returned only the current holder, so the original account was
  unreachable by its sign-up address.

This commit:

- Run the emails and accounts.normalizedEmail lookups together and
  return an array, current-email match first.
- Render email results with the recovery-phone list and label each
  with how it holds the address (primary, secondary, sign-up only).
- Update the admin API functional test for the array response.
