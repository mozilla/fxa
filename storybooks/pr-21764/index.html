Summary
fix(settings): time out the pairing scan_qr page
Description
Because:

* The v2 pairing scan_qr page had no timer, so an unscanned QR stayed.
* A config object that changes per render could restart the QR effect.

This commit:

* Adds pairing.qr_timeout_minutes (default 5) and sends it to settings.
* Times out ScanQRContainer after the QR shows and calls giveUp.
* Clears the timer on unmount and skips it if the channel fails.
* Keys the QR effect on the timeout value, not the config object.

Closes FXA-15001
