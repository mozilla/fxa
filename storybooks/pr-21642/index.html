Summary
feat(settings): record passkey alert and banner views in Glean
Description
Because:

* Settings did not record passkey alert and banner views, closes or Learn more clicks.
* The unsupported passkey row used the same click ID as the Create button.

This commit:

* Adds the alert_bar.view and banner.view Glean events.
* Lets AlertBar and Banner record a view and tag close buttons through an opt-in gleanId.
* Gives the Settings passkey alerts, Learn more links and sign-in banners their Glean IDs.
* Tags the unsupported Create button as account_pref_passkey_create_unsupported.

Closes FXA-13972
