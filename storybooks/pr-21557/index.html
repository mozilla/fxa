Summary
fix(settings): check the Sync account for the pairing TOTP gate
Description
Because:

* The pairing TOTP gate checked the current localStorage account,
  not the account Firefox Sync is signed in to
* The gate skipped the check with no session token, a failed
  profile lookup, or a cached recent code with no token

This commit:

* Gates pairing on the Sync account from fxa_status
* Verifies the pairing TOTP code with the Sync account token
* Makes AuthAllow and AuthTotp wait for fxa_status
* Makes the gate fail closed before it honours a recent code
* Uses the Sync user from the Pair bootstrap, and keeps an AuthAllow
  re-run from passing the check early

Closes FXA-14808
