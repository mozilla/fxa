Summary
fix(settings): stack delete account buttons on narrow screens
Description
## Because

- On a 320px screen, the buttons on both delete account steps overflow the page.
- The shared `cta-*` style sets `shrink-0`, and below 480px it sets `w-full`. Two full-width buttons that cannot shrink do not fit in a row that does not wrap. Measured at 320px: left edge -54px, right edge 374px.
- The ticket did not name the step. Both steps were fixed.

## This pull request

- Adds `flex-wrap` and `gap-4` to both button rows in `PageDeleteAccount/index.tsx`.
- Removes `mx-2` from the buttons. The `gap-4` keeps the same 16px space between buttons.
- Changes the step 1 buttons to `px-4 tablet:px-10`, the same as step 2.
- Adds the Playwright test "delete account buttons fit a 320px viewport on both steps" in `deleteAccount.spec.ts`.
- Behavior, test ids and l10n ids do not change.
