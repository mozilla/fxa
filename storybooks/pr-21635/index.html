Summary
feat(settings): add per-route bundle size report with a budget
Description
Because:

* No tool turns the webpack stats.json into a size for each lazy route,
  so a bundle size regression ships without notice.

This commit:

* Adds scripts/bundle-report.ts, which prints raw and Brotli JS size
  and node-jose use for each lazy route from build/prod/stats.json
* Warns, and exits 0, when a route is more than 5% over its budget
* Adds scripts/bundle-budget.json with the FXA-14803 Brotli budgets
* Adds a node:test spec in TypeScript for the route and budget rules

Closes FXA-14862
