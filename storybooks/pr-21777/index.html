fix(settings): discard stale cached session on Sync sign-in
Description

- After a browser-menu sign-out, Sync sign-in kept a dead cached session token.
- Later requests failed with errno 110 and the tab kept spinning.

- Keeps a token that another tab stored while validation was pending.
- Replaces the Sync Jest test with valid and invalid Sync cases.
- Adds a functional test for a stale session on Sync sign-in.
