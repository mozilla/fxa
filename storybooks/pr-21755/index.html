Summary
fix(settings): hide account switching when Firefox holds an unverified account
Description
Because:
- Firefox attaches an account to the profile on fxaccounts:login, before
  the session is verified, and from then on refuses to link another one.
- "Finish account setup" opened cached signin with "Use a different
  account" visible; following it hit the old merge warning dialog.

This commit:
- Tracks hasBrowserAccount in App from the fxa_status uid, verified or not.
- Hides the account switch link on Signin, SigninCached,
  SigninAlternativeAuthOptions and SigninPasswordlessCode from that flag.
- Keeps isSignedIntoFirefox verified-only for SigninDecider and PageSettings.
- Adds App and SigninDecider tests for the unverified browser account.

Closes #FXA-13191
