Summary
fix(settings): pin a Firefox desktop UA for the Pair stories
Description
Because:

- Pair reads detectDevice() on mount and redirects to /pair/unsupported
  without clearing bootstrapping, so a non-Firefox user agent leaves every
  story on the full-screen spinner.
- Reviewers open Storybook in whatever browser they happen to use, so the
  stories only rendered for some of them.

This commit:

- Adds a decorator that stubs navigator.userAgent as Firefox desktop while
  a Pair story is mounted, and restores it on unmount.
