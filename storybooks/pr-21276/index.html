Summary
refactor(auth): remove customs server and legacy customs client
Description
## Because

- The auth server rate-limits in process with `@fxa/accounts/rate-limit`. Nothing calls the customs service now.
- `lib/customs.js` kept two rate-limit paths at once, the old HTTP client and the library.
- CI still started the customs service for jobs that do not need it.

## This pull request

- Deletes the `packages/fxa-customs-server` package, about 31,000 lines.
- Strips the HTTP client from `lib/customs.js`, so it only wraps `@fxa/accounts/rate-limit`, and trims `lib/customs.spec.ts` to match.
- Drops the `customsUrl` and `customsClient` settings from the auth server config.
- Removes the customs command, the job parameter and the `CUSTOMS_SERVER_URL` entries from `.circleci/config.yml`, and the customs path from `.github/.codecov.yaml`.
- Rewrites the rate-limit section of the auth server README and points `backstage.yaml` at `resource:fxa-customs-cache`.
