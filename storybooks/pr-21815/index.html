Summary
feat(settings): send a locked-primary-password authority to pair failure
Description
Because:

- Firefox now sends signedInUser.primaryPasswordLocked in fxa_status.
- While it is locked, desktop /pair sent the user to a sign-in that cannot unlock it.

This commit:

- Sends a desktop /pair with primaryPasswordLocked true to /pair/failure.
- Records pairing.password_lock_failure once on /pair/failure for that case.
- Adds the Glean event, its wiring, unit tests and a functional test.
