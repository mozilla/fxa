refactor(profile): replace checksum dependency with node:crypto
Description
## Because

- FxA is cutting third party dependencies. The Node standard library already does this hash.
- `checksum` is the only package that pulls `optimist` into the lockfile.

## This pull request

- Removes the `checksum` dependency from `fxa-profile-server`.
- Uses `crypto.hash('sha1', value, 'hex')` for the `/profile` ETag in `profile.js` and for the `/display_name` ETag in `display_name/get.js`.
- Updates the expected ETag in `api.in.spec.ts` the same way.
- Drops `checksum` and `optimist` from `yarn.lock`.
