Summary
fix(payments): guard subscription writes on Stripe event time
Description
Because:

* fetchAndInsertSubscription wrote without stripeEventCreatedTime, so an
  older event's stale fetchAndInsertCustomer write could overwrite it
* Reading Stripe inside the transaction repeated Stripe calls on every
  contention retry

This commit:

* Reads Stripe before the transaction in fetchAndInsertSubscription
* Skips subscription writes when a same-or-newer event is stored
* Stores stripeEventCreatedTime on subscription writes
* Passes event.created from processSubscriptionEventToFirestore

Closes #PAY-3937
