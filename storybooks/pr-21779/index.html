fix(settings): show passkey already-registered message on macOS
Description
Because:
- The already-registered passkey error was typed NotSupported, so the
  add-passkey page showed a generic banner instead of its message

  triggered the PRF-less retry and a second QR prompt

This commit:
- Types AuthenticatorAlreadyRegistered as NotAllowed so its message shows
- Maps UnknownError to already-registered on macOS when passkeys exist
- Skips the PRF-less registration retry on macOS
- Adds an isMacOS user-agent helper
