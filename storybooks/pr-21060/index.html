## Because

* `main` added `reportBundleError` reporting for l10n bundle and manifest load failures.
* This branch replaced the manifest fetch with a map that the build embeds in the settings HTML.
* The two changes touched the same function, so the merge needed a resolution that keeps both.

## This commit

* Reads the l10n asset map from the `fxa-l10n-asset-map` meta tag instead of fetching `static-asset-manifest.json`.
* Keeps the `reportBundleError` plumbing from `main` and reports an unusable map through it.
* Keeps the `console.warn` fallback for consumers that pass no reporter.
* Adds the favicon link from `main` next to the new meta tag in `packages/fxa-settings/public/index.html`.
* Moves the `reportBundleError` tests onto the embedded map, and changes the unreachable manifest case to an unusable map.
