Summary
test(fxa-shared): preload chai so mocha does not race the ESM loader
Description
## Because

- `chai` was pinned at `^4.5.0` in four packages, three majors behind.
- `sinon-chai@4.0.0` declares `chai: ^5.0.0` as its peer, so `main` carries a broken peer dependency today.

## This pull request

- Bumps `chai` to `^5.3.3` in `fxa-content-server`, `fxa-shared`, `fxa-customs-server` and `fxa-geodb`. The lockfile resolves one version, 5.3.3.
- Rewrites 38 files under `fxa-content-server/app/tests/` from `import chai from 'chai'` to `import { assert } from 'chai'`. chai 5 dropped the default export.
- Adds a `transformIgnorePatterns` entry to the jest configs in `libs/shared/guards` and `fxa-admin-server`, so jest transforms chai instead of skipping it.
- Moves the five assertions in `fxa-settings/src/lib/random.test.ts` to jest's own `expect`.
- Adds `scripts/preload-chai.mjs` to `fxa-shared` and loads it from the three mocha scripts. See below.
