Summary
fix(settings): stop code input required error on blur
Description
## Because

- The code input gets focus when the page loads. If the user clicks away before they type, the "This field is required" tooltip shows before they submit.
- The cause is `mode: 'onBlur'` together with `required: true` in `FormVerifyCode`. The form runs validation on blur.

## This pull request

- Removes `mode: 'onBlur'` from the `useForm` call in `FormVerifyCode`. The form now uses the default `onSubmit` mode.
- Keeps `required: true`. The submit button stays disabled until the code is valid, so an empty submit is not possible.
- Adds a unit test that blurs the empty input and checks that no "required" error shows. The test fails before the fix and passes after it.
