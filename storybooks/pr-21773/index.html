Summary
fix(settings): improve passkey and Settings row accessibility
Description
Because:

* The passkey a11y review found screen-reader and focus gaps on the
  passkey row, list, dialogs and creation page.
* Settings row headings and CTAs announced without saying which row
  they belong to.

This commit:

* Names row headings by heading and status, and row CTAs by CTA text
  and heading ("Change Password", "Create passkey").
* Keeps disabled row CTAs focusable with aria-disabled; the passkey
  Create button is described by the limit banner.
* Renders passkeys as a list with "Delete {nickname}" and icon-only
  "Rename {nickname}" controls.
* Returns focus after passkey dialogs close and fixes the delete
  dialog description.
* Gives Cancel on the creation page context, and tests that
  LinkExternal keeps its new-window text under FtlMsg.

Closes FXA-13707
