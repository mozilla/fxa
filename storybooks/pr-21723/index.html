fix(settings): respect the stored metrics opt-out before sign-in
Description

* Signed-out pages turned metrics on, even when the stored account
  opted out.

* Keeps metrics off before sign-in when the stored account opted out.
* Recomputes the metrics pref when the current account changes.
* Turns Glean off when the metrics pref becomes false.
