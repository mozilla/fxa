Summary
fix(settings): check the Sync account for the pairing TOTP gate
Description
Because:

- Pairing checked 2FA on the current local account, not the Sync account.
- A second local account without 2FA let pairing skip the TOTP code.

This commit:

- Checks the Sync account from fxa_status in the pairing TOTP gate.
- Verifies the pairing TOTP code with the Sync account's session token.
- Fails the gate closed on a missing token or a profile lookup error.

Closes FXA-14808
