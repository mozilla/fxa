Summary
docs(adr): freeze the passkey wrap format at v1
Description
Because:

- The wrap envelope is a compatibility contract the server cannot migrate;
  a format change after production writes sends every passkey user back to
  their password with no explanation.
- The policy and the reasoning were spread across five tickets with no
  single record.

This commit:

- Adds ADR 0053: the freeze, the rejected options, what counts as a format
  change, what holds it in place, and the shape of a v2 (table per version).
- Moves the per-value design rationale into the passkey-crypto README.
- Corrects doc comments: P-521 leading-zero frequency, hpke import surface.
- Adds CODEOWNERS entries for the crypto module, the passkey lib, and the
  passkeyWraps migrations.

Closes FXA-14155
