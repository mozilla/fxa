Summary
perf(settings): lazy-load scoped-keys in the OAuth finish hook
Description
Because:

* The static scoped-keys import shipped node-jose and node-forge with
  every page that imports the OAuth finish hook.
* A render-time wantsKeys() call threw on an integration without it,
  which made React render again and broke the App test.

This commit:

* Imports scoped-keys on demand in constructKeysJwe.
* Prefetches the chunk on mount when the integration wants keys.
* Calls wantsKeys() in the prefetch effect, in a try/catch.

Closes FXA-14854
