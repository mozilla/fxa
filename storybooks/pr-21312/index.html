## Because

- `lib/oauth/hooks.tsx` finishes every OAuth sign-in in fxa-settings. Its tests covered only the passkey kB stash and the permissions gate. Its data checks, key scope choice, error mapping and redirect logic had no unit tests.

## This pull request

- Adds unit tests in `hooks.test.tsx` for `lib/oauth/hooks.tsx`. The tests cover:
  - `checkOAuthData` errors, read through `oAuthDataError`.
  - The key scope choice: the URL scope when present, or the `apps/oldsync` fallback for native flows.
  - An `accountKeys` failure, which resolves to `TRY_AGAIN`.
  - The errno passthrough of `UNVERIFIED_SESSION`, `TOTP_REQUIRED` and `INSUFFICIENT_ACR_VALUES`. Other errnos map to `TRY_AGAIN`.
  - The Sync web channel redirect with the integration state. Other flows get a URL built from the relier redirect URI, with the response state.
  - `useOAuthKeysCheck`.
- The new `describe` blocks sit at the end of the file. This keeps the rebase simple for the open PR that changes the same file.
- There are no source changes.
