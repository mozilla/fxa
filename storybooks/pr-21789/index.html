Summary
feat(settings): record why a pairing failed on each device
Description
Because:

- timeout_view reported `timeout` for every failure, so a device that gave up could not be told from one that lost signal.
- Pages reached with no reason were also counted as timeouts.
- The channel hash was only set on supplicant pages, so the two devices' events could not be joined.

This commit:

- Adds a `cause` extra to both timeout_view events: peer_closed, connection_lost or error.
- Derives the cause from how the pairing socket closed, on both the supplicant and the authority.
- Reports `reason` as `unknown` when the page is reached without a recognised reason.
- Records the channel id the authority creates, so its events carry the channel hash.

Closes FXA-15085
