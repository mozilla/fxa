Summary
chore(deps): remove node-fetch in favor of the built-in global fetch
Description
## Because

- The ticket asks for a `node-fetch` 3.x upgrade, but 3.x is ESM-only and this repo is mostly CommonJS. That is the breakage the ticket reports.
- The root `engines` field now requires Node `^24.15.0`, and Node has supplied a global `fetch` since version 18.

## This pull request

- Removes `node-fetch` and `@types/node-fetch` from the root `package.json`. That was the only place either one was declared.
- Deletes the import in `basket.service.ts`, `cancel-jobs.mjs`, and `modules-to-test.js`. Nothing replaces it, no polyfill and no wrapper.
- Updates `yarn.lock` to match, because CI installs with `--immutable`.
