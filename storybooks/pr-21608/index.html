Summary
feat(settings): derive page title from h1 and focus it in AppLayout
Description
Because:

* Most AppLayout pages pass no title, so the tab title stays "Mozilla accounts".
* Focus falls to body after a route change, so screen readers announce nothing.

This commit:

* Derives the page title from the first main h1 when no title or CMS pageTitle is set.
* Focuses the main h1 with tabindex -1 after mount and loading, unless something has focus.
* Hides the focus ring on that h1 and removes the TODO.
* Adds AppLayout tests and updates Signin expectations and snapshots.

Closes FXA-6803
