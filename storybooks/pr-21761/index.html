Summary
feat(auth): add POST /account/sync_data/destroy
Description
Because:
- Users need to delete their Sync data from Settings once per-engine toggles in Firefox stop deleting server data.
- Tokenserver now exposes an FxA-authenticated delete endpoint (STOR-713).

This commit:
- Add a route that mints a short-lived fxa-sync-delete+jwt assertion and calls tokenserver.
- Require an mfa:sync_data token on a session that has re-entered its password.
- Gate it behind syncDataDeletion.enabled, rate-limit it as syncDataDestroy, and count outcomes in StatsD.
- Record the account.sync_data_deleted security event and a Glean event when data was deleted.
- Add destroySyncData to fxa-auth-client, Swagger docs, and unit and integration tests.

Relates to FXA-14946
