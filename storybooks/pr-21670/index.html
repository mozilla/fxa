perf(settings): preload en main.ftl and Index route chunks from the HTML
Description
Because:
- The browser finds en/main.ftl and the Index route chunks only after the entry JS runs and l10n loads.

This commit:
- Adds a __L10N_PRELOAD__ placeholder to the fxa-settings index.html.
- Fills it in beta-settings.js with a preload link for the hashed en main.ftl under l10n.baseUrl.
- Names the IndexContainer chunk "Index".
- Adds a prod-only webpack plugin that preloads the Index route chunks at low priority.
- Adds mocha tests for the l10n preload and its empty cases.
