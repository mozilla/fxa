Summary
fix(settings): ask 2FA accounts for TOTP before v2 pairing starts
Description
Because:
- A 2FA account was asked for TOTP after the v2 pairing channel was open.
- The 2FA pairing specs sign in with TOTP and pair at once, so the fresh code skipped the prompt.

This commit:
- Asks for TOTP on ScanQR before createChannel() and drops it from ApproveSignIn.
- Records totpVerifiedAt when a code is verified at sign-in or on AuthTotp.
- Skips the pairing prompt for a code newer than pairing.totp_max_age_minutes.
- Adds forgetTotpVerification so the 2FA pairing specs still assert the prompt.

Closes FXA-14774
