Summary
fix(react): retry l10n bundle fetch and skip network failures
Description
Because:

- Dropped connections and aborted fetches report to Sentry as l10n bundle failures, though the bundles are deployed and resolve.
- A transient drop leaves the user on English when one retry would load their locale.

This commit:

- Retries a thrown l10n bundle fetch once.
- Skips reporting network TypeErrors and AbortErrors that persist after the retry.
- Keeps reporting HTTP errors, map gaps and other thrown errors.

Fixes FXA-14572
