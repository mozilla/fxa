Summary
perf(settings): lazy-load Settings sub-pages behind one spinner
Description
Because:

* The Settings chunk held all 15 sub-page modules, so /settings loaded code most visits do not use.
* A cold /settings load showed a spinner, the AppLayout card, then a second spinner.

This commit:

* Loads the 15 Settings sub-page modules with React.lazy, with the same exports.
* Wraps the /settings/* route in one Suspense with a full-screen LoadingSpinner.
* Adds the same Suspense to the Settings test harness and waits with findBy* in routing tests.
* Adds an App test for the /settings/* loading fallback.

Closes FXA-14857
