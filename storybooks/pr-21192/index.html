Summary
feat(settings): add passkey wrap creation
Description
Because:
- Passwordless Sync needs kB sealed to a passkey's PRF output before a
  wrap can be stored.

This commit:
- Adds createPasskeyWrap, sealing kB into a wrap envelope bound to the
  account the mfa:passkey proof names and storing it under that proof.
- Reopens the envelope before storing it, catching platform crypto that
  seals what it cannot unseal.
- Labels only client-decided failures; server refusals come back as a
  HandledError, with errno 235 added to AuthUiErrors so it localizes.
- Zeroes kB, the PRF output and the reopened copy once sealing has been
  tried.
- Adds usePasskeyWrapCreation, a single-flight call with a loading flag.

Closes #FXA-14425
