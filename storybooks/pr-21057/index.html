## Because

- The hooks in `fxa-settings` were being split into `lib/hooks/[name]/index.tsx`, one directory each. Most of that work already shipped, but three hooks were left behind in `lib/hooks.tsx`.
- The ticket also asks for a `lib/hooks` barrel, so callers can write `import { useHookName } from '../../lib/hooks'`.

## This pull request

- Moves `useFocusOnTriggeringElementOnClose`, `useEscKeydownEffect` and `useChangeFocusEffect` into `lib/hooks/[name]/index.tsx`, following the nine hook directories that moved earlier.
- Splits `lib/hooks.test.tsx` into an `index.test.tsx` beside each hook. All five cases carry over as they were.
- Adds the `lib/hooks/index.ts` barrel that re-exports the three hooks.
- Deletes `lib/hooks.tsx` and `lib/hooks.test.tsx`.

This is a move, so there is no behaviour change. The five importing components still say `from '../../../lib/hooks'`, which now resolves to the barrel instead of `hooks.tsx`. That means no import churn, and the other imports under `lib/hooks/` are untouched.
