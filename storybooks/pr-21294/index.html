feat(settings): add React page for /update_firefox
Description
## Because

- Browsers too old for a Mozilla account land on /update_firefox. Only the Backbone content server renders it today.
- FxA is moving pages from the content server to fxa-settings.

## This pull request

- Adds a React `UpdateFirefox` page in fxa-settings, with Fluent strings in `en.ftl`, a story, and a unit spec.
- Serves /update_firefox from React when the `postVerifyOtherRoutes` flag is on.
- Keeps `get-update-firefox.js` as the server fallback when the flag is off.
- Keeps /download_firefox on the server. The button links to it with the allowed query params and the flow data.
- Logs `flow.begin` and `flow.update-firefox.view` on mount, because the React route bypasses the server route that logged them.
