Summary
fix(auth): return errno 237 for passkey wrap creation without reauth
Description
Because:
- POST /passkey/wraps refused a session with no password reauth with errno 223.
- fxa-settings starts a passkey step-up on 223, and that step-up cannot pass the guard.

This commit:
- Adds AppError.passkeyWrapReauthRequired() with errno 237, status 401.
- Throws it from the reauth guard in passkey-wraps.ts.
- Keeps errno 223 for a token that is not bound to the credential.
- Lists errno 237 in the swagger docs.
- Adds unit, remote and settings tests for the new errno.

Closes FXA-14847
