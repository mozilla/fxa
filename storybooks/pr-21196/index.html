Summary
feat(settings): serve the default favicon from the CDN
Description
## Because

- The settings page declared no icon link. The browser then asked the app server for `/favicon.ico` instead of loading the icon from the CDN.
- `Head` always rendered an icon link. When `favicon` was undefined, that link had an empty `href` and replaced the static default.

## This pull request

- Adds a default icon link to `index.html`. The build script sets `%PUBLIC_URL%` to the prod CDN, the stage CDN, or a relative path.
- Renders the Helmet icon link in `Head` only when the `favicon` prop has a value.
- Adds unit tests for the two `Head` cases.
