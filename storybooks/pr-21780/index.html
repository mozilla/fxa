Summary
fix(settings): disable Save after the first secondary email submit
Description
Because:

* A double click on Save in the add secondary email page sent two POST /mfa/recovery_email requests, so the user got two emails.
* Save used account.loading, a plain field that does not re-render the page.

This commit:

* Adds an isSubmitting state that disables Save and ignores a second submit.
* Clears the state on error so the user can submit again.
* Adds unit tests for a double click and for a retry after an error.

Closes FXA-14364
