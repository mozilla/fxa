Summary
refactor(auth-server): replace dedent with a local tagged template
Description
## Because

- FxA is cutting its dependency count (parent FXA-13426).
- The `dedent` package has one job in fxa-auth-server. It is a tagged template in the swagger API docs.
- One escape in the docs needs care. `docs/swagger/oauth-server-api.ts:156` writes a raw `\\n`, and the rendered output must keep a backslash before the line break.

## This pull request

- Adds `docs/swagger/shared/dedent.ts`, a local tagged template that strips the common indentation.
- Points the 18 swagger description modules at the local helper.
- Drops `dedent` and `@types/dedent` from the fxa-auth-server package and refreshes `yarn.lock`.
- Adds `docs/**/*.spec.ts` to the Jest unit project and `docs/**/*` to the tsconfig include, so the spec runs and gets type-checked.
- Adds a regression test in `docs/swagger/shared/dedent.spec.ts` for the raw `\\n` escape at `docs/swagger/oauth-server-api.ts:156`. The helper must render it as a backslash and a newline, which keeps the Markdown hard break.
