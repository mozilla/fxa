Summary
fix(settings): stop code input required error on blur
Description
## Because

- The shared code-entry form (`FormVerifyCode`) auto-focuses its input. If you tab away from the empty input, a "required" error shows before you submit anything.
- The bug affects these pages: sign-in confirmation, unblock, recovery code, passwordless code, sign-up confirmation and pairing TOTP.

## This pull request

- Removes `mode: 'onBlur'` from `useForm` in `FormVerifyCode`. react-hook-form now uses its default onSubmit mode.
- Adds a unit test that tabs away from the empty input and checks that "This field is required" does not show.
- Gives the negative `findByText` in the new test a 100 ms timeout. The 1000 ms default added about 1 s to the suite.

## Issue that this pull request solves

Closes: FXA-14612
