Summary
fix(pair): keep the pairing-complete marker across mobile reloads
Description
Because:
- Firefox for Android reloads the supplicant's original URL after the
  OAuth login, sometimes more than once.
- The v2 branch cleared the completion marker on first use, so a later
  load reopened the consumed channel and showed the timeout or the old
  "pair failed" screen, depending on whether fxa_status answered in time.
- The /pair entry never checked the marker at all.

This commit:
- Keeps the fxa.pair.complete marker instead of clearing it.
- Routes a completed channel to sync_success from /pair as well as
  /pair/supp, replacing the history entry.
- Removes the unused clearChannelComplete helper.
- Covers repeated loads of a completed channel in both page suites.

Closes #FXA-14606
