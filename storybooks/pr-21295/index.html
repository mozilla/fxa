feat(settings): serve /subscriptions redirects from React
Description
## Because

- The `/subscriptions` and `/subscriptions/products/:productId` redirects still come from the Backbone content-server views.
- The Jira comments planned to keep these routes in Backbone until FXA-6117 (Decommission Backbone). The owner decided to move them to React now.

## This pull request

- Adds the `SubscriptionsRedirect` page in fxa-settings for both routes, behind the `postVerifyOtherRoutes` feature flag.
- Keeps parity with the Backbone views: `allowUnauthenticatedRedirects`, `?signin=` to force sign-in first, and `usePaymentsNextSubscriptionManagement` to choose `subscriptions/landing`.
- Passes the `subscriptions` config from content-server to fxa-settings (`beta-settings.js`, `config.ts`).
- Keeps a literal `+` in forwarded query params. `URLSearchParams` reads `?plan=a+b` as "a b", but the Backbone parser keeps the `+`.
