feat(admin-panel): add Storybook and component stories
Description
## Because

- fxa-admin-panel had no Storybook, so reviewers could not look at its components on their own.
- Admin panel pages call `adminApi` when they render and when a user clicks an action, so they show nothing without a server.

## This pull request

- Adds Storybook 8 (react-webpack5) to fxa-admin-panel, with `storybook` and `build-storybook` scripts and an nx `build-storybook` target. The existing deploy-storybooks workflow picks up that target.
- Adds `.storybook/main.js`, a `webpack.config.js` that reuses the fxa-react Storybook config, and `preview.tsx`. The preview wraps each story in a router, a fake admin user and the guard context.
- Adds `stubAdminApi` and `stubAdminApiErrors` loaders in `src/lib/storybook.ts`. Page stories use them to show success and error states without a server.
- Adds an `index.stories.tsx` for every component, plus `mocks.tsx` for Account, PageDomainBlocklist, PageEmailBlocklist, PageOAuthScopes and PageWafTokens.
- Stubs the account-action adminApi calls in the Account, DangerZone, EmailBounces and PageAccountSearch stories, restores the real adminApi before each story, and adds the fxa-react localization decorator (review feedback).
