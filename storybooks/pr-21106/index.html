Description
## Because

- Integration suites create a throwaway MySQL schema per run and never drop it. The schemas pile up on developer machines and in CI containers.
- A run that crashes before its teardown leaves its schema behind for good.

## This pull request

- Adds `testAccountDatabaseTeardown`. It drops the throwaway schema, then closes the pool.
- Reads the schema name from the connection, so `testAccountDatabaseSetup` keeps its signature.
- Drops orphan schemas older than 3 hours at setup time. The age limit lets a concurrent run keep its own schema.
- Replaces `await db.destroy()` with the new teardown in 12 integration specs.
- Adds `tests.spec.ts` for the teardown and the sweep.
