Summary
fix(settings): fit bounce polling under the server rate limit
Description
Because:

- A fixed 5s poll makes 120 requests over the 10 minute cap, but the server
  allows 100 per IP per 15 minutes, so the deadline was never reachable.
- That rule is keyed on IP and blocks for 15 minutes, so one signup tab took
  bounce detection down for everyone behind the same address.

This commit:

- Backs the interval off to 30s after the first minute, for 30 requests total.
- Skips the effect when there is no email to check.
- Replaces the interval with a timeout chain owned by the effect run.
