Summary
fix(admin-server): find the basket token by primary email on unsubscribe
Description
Because:

- The admin unsubscribe looked up the basket token with accounts.email, the signup email.
- Basket can move its record to the new primary email, so the lookup found no token.

This commit:

- Reads the primary email from emails and looks up the basket token with it first.
- Falls back to accounts.email when the primary email has no token.
- Adds unit cases for the lookup order.

Closes FXA-15106
