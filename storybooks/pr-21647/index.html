Summary
perf(settings): load Settings and CAD Glean events lazily
Description
Because:

- Every route bundled the Settings, CAD and DTM Glean metric modules.
- The pairing hand-off navigates right after its events, so they cannot wait on a chunk.
- A lazy event can be lost if the page unloads before it is sent.

This commit:

- Moves 87 recordEventMetric cases to lib/glean/lazy-events.ts, loaded by dynamic import.
- Keeps the dtmMobile and download Firefox view events eager.
- Awaits recordEventMetric in the queued lambda to keep the call order.
- Waits for GleanMetrics.isDone() before the promo banner hardNavigate to /pair.
- Adds a table test, a call order test and a banner navigation test.

Closes FXA-14859
