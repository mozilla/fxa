fix(settings): Fix app store fallback on deep link failure
Description
Because:

- On iOS, if a user clicked 'Continue in Firefox' but didn't actually have Firefox, they'd hit a dead end.
- In this case we want the user to be sent to app store, so they can download Firefox.

This commit:

- Routes the Safari deep link through onAttempt so a timeout sends the user to the app store
- Ignores a focus event in store-fallback that no blur preceded
- Catches per-ping errors in submitPing so the mutex is released
