Summary
chore(nx): hash yarn.lock into every cached target
Description
Because:
- Nx only hashes the npm packages a project imports, so removing a
  type-only package such as @types/chai leaves every hash unchanged and
  the cache replays a green result.
- shared-guards:test-unit stayed cached and green for a week after
  #21580 removed its chai types; the break only surfaced once the Node
  bump changed `node -v` on train-348.

This commit:
- Adds yarn.lock to sharedGlobals so any lockfile change invalidates
  the cache for all targets.
