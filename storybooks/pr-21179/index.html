Summary
fix(settings): make the Pair stories independent of the browser UA
Description
Because:

- Pair reads detectDevice() on mount and redirects to /pair/unsupported
  without clearing bootstrapping, so a non-Firefox user agent left every
  story on the full-screen spinner.
- Reviewers open Storybook in whatever browser they happen to use, so the
  stories only rendered for some of them.

This commit:

- Adds an optional device prop to Pair, defaulting to detectDevice().
- Passes Devices.FIREFOX_DESKTOP from the 9 Pair stories.
