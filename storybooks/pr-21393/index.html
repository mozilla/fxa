Summary
fix(auth): accept stored OAuth scopes in attached_clients response
Description
Because:

* The response scope regex is stricter than ScopeSet, so a stored scope
  like `...#read` fails validation and attached_clients returns a 500

This commit:

* Exports ScopeSet's VALID_SCOPE_VALUE from fxa-shared/oauth/scopes
* Adds a response-only storedScope validator for attached_clients
* Leaves the request scope validator unchanged
* Updates the Swagger validator list and adds storedScope unit tests

Fixes FXA-14573
