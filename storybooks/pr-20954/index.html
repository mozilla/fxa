Summary
feat(settings): add mobile "Connect this device" pairing card
Description
Because:
- The redesigned desktop-to-mobile pairing flow needs a mobile card that
  asks the user to confirm connecting the device in their hand, showing the
  account email plus the desktop device's browser, estimated location, and
  IP address so they can verify the request before connecting.

This commit:
- Adds `ConnectThisDevice` under `packages/fxa-settings/src/pages/Pair2/
  Supplicant/`, a presentational card taking `email` and `authDeviceInfo` as
  props with optional `onConnect`/`onCancel`. Button wiring, routing, and
  metrics are deliberately deferred to the flow-wiring ticket.
- Adds the Figma-exported Firefox lockup and sync illustration, `en.ftl`
  strings, Storybook stories, and tests including a real Fluent-bundle check
  that every string id resolves.
- Extends `DeviceInfoBlock` with additive, defaulted `className` and
  `showDeviceName` props so the card can render it as the design's bordered
  box, reusing the existing localized browser/location/IP strings instead of
  duplicating them.

Closes #FXA-14233
