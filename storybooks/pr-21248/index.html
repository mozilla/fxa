Summary
fix(settings): split set password subscription heading in two
Description
## Because

- An l10n reviewer asked if the combined heading could be two strings.
- `set-password-subscription-heading-with-product` held `<span>` markup inside one FTL string, so each translator had to keep the tag in place.
- Screen readers read the heading and the product line as one phrase.

## This pull request

- Removes `set-password-subscription-heading-with-product` from `en.ftl`. No other file uses the id.
- Adds `set-password-subscription-subheading = Continue to { $productName }` for the product line.
- Renders two `FtlMsg` blocks in `SetPassword/index.tsx`: the `h1` with `card-header`, and a sibling `<p className="card-subheader">` when the link carries `product_name`.
- Updates the tests. The `h1` name is now "Create a Mozilla account" alone, the subheading has its own assertion, and the case without `product_name` asserts that the subheading is absent.
