Summary
fix(settings): destroy the browser session token on sign-out
Description
Because:

* A forced web sign-in (prompt=login) can replace the stored session
  token without a reload, so Firefox holds a different one.
* Settings sign-out destroyed only the stored token, and Firefox handles
  fxaccounts:logout locally, so its session and device stayed live.

This commit:

* Asks Firefox for its token via fxa_status on sign-out, in Firefox only.
* Has Session.destroy also destroy a same-uid browser token, best effort.
* Adds Session and DropDownAvatarMenu unit tests.
* Adds an oauth_webchannel_v1 functional spec reading Firefox's token.

Closes #FXA-14613
