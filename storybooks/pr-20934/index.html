Summary
feat(metrics): add cad_pair_success Glean event
Description
Because:
 - No analytics event marks the end of the desktop-to-mobile pairing flow,
   so successful pairings cannot be distinguished from drop-offs earlier in
   the funnel.

This commit:
 - Adds a cad_pair.success Glean UI event, emitted when the "Device
   connected" screen is displayed. Both pairing state machines only reach
   that screen after the desktop approves AND the mobile device confirms,
   making it an end-to-end success signal rather than a per-side intent
   like cad_approve_device.submit or cad_mobile_pair.submit.
 - Emits it from the Backbone and React implementations of the screen,
   since the pair routes are still split behind showReactApp.pairRoutes.

Closes #FXA-12945
