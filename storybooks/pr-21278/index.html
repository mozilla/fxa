Summary
chore(deps): remove bluebird from profile-server and geodb
Description
## Because

- The monorepo drops `bluebird` as part of the dependency reduction work.
- `fxa-profile-server` kept a `lib/promise.js` shim that re-exported Bluebird to 14 files.
- The shim called `onPossiblyUnhandledRejection()`, which hid floating rejections.

## This pull request

- Removes `bluebird` from `fxa-geodb` and `fxa-profile-server`, and deletes the `lib/promise.js` shim.
- Replaces the Bluebird-only calls `defer`, `each`, `fulfilled`, `promisify`, `using`, `done`, `spread`, and promise `map`.
- Adds `_withConnection` in `lib/db/mysql/index.js`, which releases the connection in a `finally` block.
- Adds a `catch` that logs to the two unwaited `profileCache.drop` chains in `lib/events.js`.
- Ports the three integration specs to native promises and a local `delay` helper.
