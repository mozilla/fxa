Summary
fix(settings): treat incorrect email case as incorrect password
Description
Because:

* Settings showed "Incorrect email case" for a wrong password, and in the
  banner instead of under the password field.
* Sign-in retried a 120 after sending v2 credentials, which can't succeed.

This commit:

* Adds isIncorrectPassword() and renders errno 120 as the 103 message.
* Shows 120 as a field error on sign-in, unblock, change password, delete
  account, recovery key and passkey fallback.
* Returns INCORRECT_PASSWORD without retrying from the Signin and
  SigninUnblock containers when v2 credentials got a 120.
* Stops the SigninUnblock 120 retry from running more than once.

Closes #FXA-14934
