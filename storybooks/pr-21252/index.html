Summary
fix(settings): keep QR quiet zone under forced-colors mode
Description
Because:

* The QR code's quiet zone is the white padding on the wrapper, not part
  of the SVG. Windows High Contrast Mode repaints that padding with the
  system canvas colour, so the code's edges bleed into the background.
* Older Android scanners cannot read a QR without a quiet zone, so
  desktop pairing fails for those users while newer scanners cope.

This commit:

* Adds `forced-color-adjust-none` to the shared QRCode wrapper so its
  colours survive forced-colors mode; the SVG, spinner overlay and logo
  chip inherit it.
* Adds a unit test guarding the class on the wrapper.

Closes #FXA-14488
