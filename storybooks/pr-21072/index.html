Summary
task(passkey): Add passkeyWraps model, repository and service
Description
Because:
* The wrap endpoints (FXA-13142) need to read and write passkeyWraps.
* A wrap's fixed-width binary fields have to round-trip untouched, since a
  corrupted envelope cannot be reconstructed.
* The envelope format has no discriminator, and adding one costs nothing
  only while no rows exist.

This commit:
* Adds patch 196-197, a version column on passkeyWraps, so a row can be
  classified without decrypting it.
* Adds the PasskeyWraps kysely type, a factory and an integration-test
  fixture, with version stamped from ENVELOPE_VERSION.
* Narrows PasskeyWrapUpdate to the two hpke fields and updatedAt, so a kB
  re-seal cannot overwrite what protects skR.
* Adds errnos 234-237 with AppError factories, filling the reserved gap.
* Adds the wrap repository and service store/get/update, with ownership
  scoped in SQL and idempotency by full-envelope compare.
