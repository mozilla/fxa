Summary
feat(auth): send Glean server-deletion-request ping on account deletion
Description
Because:

* Data Engineering finds FxA account deletions by parsing auth-server
  logs (fxa_delete_events), which is fragile and blocks decommissioning
  Amplitude
* Glean server telemetry now supports a server-deletion-request ping that
  the pipeline can consume directly (DENG-4079)

This commit:

* Sends account.user_id and account.user_id_sha256 in the built-in
  server-deletion-request ping and regenerates server_events.ts
* Submits the ping wherever DB.deleteAccount and accountDeleted.byCloudTask
  are logged
* Keeps the existing deletion logs for a parallel validation period
