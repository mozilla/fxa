Summary
perf(settings): load Settings and CAD Glean events lazily
Description
Because:

* Every route bundled the Settings, CAD and DTM Glean metric modules.
* A lazy event can be lost if the page unloads before it is sent.
* A hung lazy chunk must not block the pair link navigation.

This commit:

* Moves 87 recordEventMetric cases to a dynamically imported chunk.
* Keeps the dtmMobile and download Firefox view events eager.
* Awaits recordEventMetric in the queued lambda to keep the call order.
* Bounds the promo banner wait for GleanMetrics.isDone() to 500 ms.

Closes FXA-14859
