Summary
perf(shared): replace pruneSessionTokens Lua script with a WATCH transaction
Description
Because:
- The pruneSessionTokens Lua script blocks Redis while it runs.
- A prune must not drop a token that touchSessionToken writes at the same time.

This commit:
- Removes the pruneSessionTokens_1 Lua script and its command.
- Prunes in TypeScript with WATCH, GET, MULTI and EXEC, and retries up to 3 times.
- Counts the redis.pruneSessionTokens.conflict StatsD metric when it gives up.
- Runs prunes one at a time on their own duplicate() connection.
- Deletes an unparseable blob, as getSessionTokens does.

Closes FXA-14945
