Summary
fix(settings): send services.sync on fx_desktop_v3 login
Description
Because:
- Firefox only configures Sync from the login message when `services.sync`
  is present; SyncDesktopV3Integration inherited the base `undefined`.
- Legacy content-server sent `services.sync = {}` for v3; the React port
  did not carry it over, so v3 sign-in left the account connected but
  Sync off.

This commit:
- Override getWebChannelServices on SyncDesktopV3Integration to return
  `{ sync: syncEngines || {} }`.
- Add a unit test for the override.

Closes #FXA-14554
