Summary
perf(shared): replace pruneSessionTokens Lua script with a WATCH transaction
Description
Because:

* The pruneSessionTokens_1 Lua script runs the prune inside Redis.
* A prune is opportunistic, so callers do not need to wait for it.

This commit:

* Replaces the script with a WATCH, MULTI and EXEC prune in TypeScript
* Runs prunes one at a time on a duplicate Redis connection
* Tries each prune once and counts a conflict or an error in StatsD
* Makes pruneSessionTokens fire and forget
* Makes close() finish queued prunes, then quit both connections

Closes FXA-14945
