Summary
fix(settings): respect the stored metrics opt-out before sign-in
Description
Because:

* A signed-out user whose stored account opted out still sent metrics.
* A same-uid opt-out did not recompute metricsEnabled, and it left the legacy Metrics client on.

This commit:

* Reads metricsEnabled from the stored account before sign-in.
* Recomputes it when currentAccountUid or accounts change.
* Turns off Glean and the legacy Metrics client on an opt-out, only when signed out.
* Adds App tests for these cases.

Closes FXA-7105
