Summary
fix(settings): skip passkey registration on a challenge mismatch
Description
Because:

- On Firefox for Android, create() can return a credential signed over
  another challenge, so registration/finish fails and the device keeps an
  orphan passkey.

This commit:

- Compares the clientDataJSON challenge with the registration/start one.
- On a mismatch, skips registration/finish and shows the add-passkey error.
- Records the frontend error event with reason challenge_mismatch.
- Adds unit tests and a functional test for the mismatch path.

Closes FXA-14286
