Summary
feat(feature-flags): add admin-managed feature flag POC
Description
Because:
  - Turning behaviour on or off in an environment currently needs a config
    change and a deploy.
  - An unreleased feature's name should not be published before it launches.

This commit:
  - Adds a featureFlags table and an admin panel page to manage flags.
  - Serves enabled flag names from auth-server GET /v1/feature-flags, cached
    per process for a configurable TTL.
  - Adds @fxa/shared/feature-flags for reading flags from clients.
  - Logs every flag change with the actor, the action, and the prior state.
  - Gates a demo banner in Settings on my-test-flag.
