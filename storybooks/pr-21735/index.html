Summary
chore(ci): keep junit results on cached lib test runs and don't fail uploads on none
Description
Because:

- Lib test targets override `outputs` with coverage only, so junit XML is never
  stored in the Nx cache; a fully cached tag build has nothing to upload to GCS.
- The upload step exits 1 when it finds no XML, which failed the v1.349.1
  "Integration Test - Libraries" job once fxa-geodb's mocha results were gone.

This commit:

- Adds `artifacts/tests/{projectName}` to lib test-unit/test-integration outputs.
- Points the 11 stray jest-junit outputDirectory values at `artifacts/tests/<projectName>`.
- Makes upload_to_gcs log and exit 0 when no result files match.
