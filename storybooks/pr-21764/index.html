Summary
fix(settings): time out the pairing scan_qr page
Description
Because:

- The v2 pairing scan_qr page had no timer and left only on a failed channel.
- The resumable authority socket reconnects, so an unscanned QR stayed open.

This commit:

- Adds the pairing.qr_timeout_minutes config (default 5) and sends it to settings.
- Starts a timer in ScanQRContainer after the QR shows and calls giveUp at the limit.
- Clears the timer on unmount, and skips it when the channel is not created.
- Adds jest fake-timer tests for the timeout and the no-fire cases.

Closes FXA-15001
