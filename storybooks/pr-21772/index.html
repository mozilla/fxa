Summary
perf(shared): prune session tokens with a WATCH transaction
Description
Because:
- The pruneSessionTokens_1 Lua script blocks other Redis clients while it runs.
- A prune must keep a token that touchSessionToken writes at the same time.
- A skipped prune must not leave a deleted session's entry in Redis for good.

This commit:
- Prunes with WATCH, GET, MULTI and EXEC on a duplicate() connection.
- Skips without retrying when a prune is running, on conflict, or on a no-op.
- Makes db.sessions prune cached entries with no MySQL token, without waiting.
- Adds SESSION_TOKENS_PRUNE_SERVER_SIDE, on by default; off restores the Lua prune.
- Counts each prune outcome under redis.pruneSessionTokens.

Closes FXA-14945
