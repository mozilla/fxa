fix(settings): stack delete account buttons on narrow screens
Description
## Because

- The Cancel and Continue buttons on the delete account page were not mobile-responsive. They sat in one non-wrapping row with fixed side margins and wide padding.

## This pull request

- Adds `flex-wrap` and `gap-4` to both button rows in `PageDeleteAccount/index.tsx`, so the buttons stack when the screen is narrow.
- Removes the `mx-2` margins from the buttons on both steps. The gap replaces them.
- Changes the step 1 buttons to `px-4 tablet:px-10`. The step 2 buttons already used this padding.
