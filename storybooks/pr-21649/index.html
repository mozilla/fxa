Summary
fix(settings): sync html lang and dir with the saved locale
Description
Because:

* The provider did not set html lang and dir from a saved locale on
  mount or on a storage event, so a saved RTL locale showed LTR.

This commit:

* Sets lang and dir in one effect on currentLocale.
* Keeps the lang-fix.js values on first load with no saved locale.
* Removes the duplicate writes in switchLanguage and
  clearLanguagePreference.
* Uses the browser locale when another tab removes the preference.
* Ignores storage events for keys other than the locale key.

Closes FXA-14885
