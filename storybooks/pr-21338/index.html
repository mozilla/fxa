Summary
fix(auth): fall back to stored sku for Play RTDN without subscriptionId
Description
Because:

* Google Play RTDN messages can omit subscriptionId, which the v1
  purchases.subscriptions.get call requires, producing an opaque 500

This commit:

* Uses the Firestore purchase's sku when subscriptionId is missing
* Throws a named MISSING_SKU error when neither is available, so the
  500 is explicit and Pub/Sub redelivers the notification
* Adds MISSING_SKU to the Google Play PurchaseQueryError enum
