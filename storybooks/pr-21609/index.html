Summary
fix(settings): render Banner content after mount for screen readers
Description
Because:
- Screen readers reliably announce only changes to a live region that already exists.
- The Banner inserted its live region with its text, so the text was often not announced.

This commit:
- Adds a `ready` state to Banner, set by one useEffect after mount.
- Renders the live region first with only id, role, aria-live and tabIndex.
- Adds className, onAnimationEnd and children to the same node after the effect.
- Adds a MutationObserver test for the status and alert regions.
- Changes five consumer specs from getByText to await findByText.

Closes FXA-10912
