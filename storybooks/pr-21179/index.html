Summary
fix(settings): decouple Pair stories from the UA and unwrap CAD stories
Description
Because:

- ConnectAnotherDevice renders its own AppLayout, so wrapping it again in
  each story nested a duplicate header, card and full-height container.
- Pair reads detectDevice() on mount and redirects to /pair/unsupported
  without clearing bootstrapping, so its stories left only the spinner in
  any browser other than Firefox.

This commit:

- Removes the AppLayout wrapper from all 10 ConnectAnotherDevice stories.
- Adds an optional device prop to Pair, defaulting to detectDevice(), and
  passes Devices.FIREFOX_DESKTOP from the 9 Pair stories.
- Covers the override with tests that render under a non-Firefox user agent
  and assert the detectDevice() fallback still redirects.
