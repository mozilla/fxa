Summary
fix(auth): disable passwordless Sync safely on bad PRF config
Description
Because:

* A prfSalt that is not base64url made the auth server exit at startup.
* The wrap routes stayed on when sign-in could not request PRF.

This commit:

* Normalizes a malformed prfSalt to '' and adds isPrfSigninConfigured.
* Gates the wrap routes on a usable PRF config and warns once at startup.
* Makes passwordlessSyncEnabled() also require the passkey master flags.
* Adds an integration spec that starts the server with a malformed salt.

Closes FXA-15078
