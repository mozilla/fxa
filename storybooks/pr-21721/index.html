perf(shared): replace pruneSessionTokens Lua with WATCH transaction
Description
Because:

* The pruneSessionTokens_1 Lua script blocks Redis while it runs.

This commit:

* Replaces the script with a WATCH, GET, MULTI and EXEC prune in RedisShared.

* Makes close() wait for queued prunes and quit the prune connection.
* Disconnects the prune connection in the Redis down spec teardown.
