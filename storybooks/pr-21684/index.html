Summary
feat(settings): switch the integration in-app instead of hard-reloading
Description
Because:

* Routes called hardNavigate only to rebuild the integration, which
  dropped location state and restarted the app.
* After an in-app switch, a superseded session check could write stale
  signed-in state.

This commit:

* Lets a route switch the integration in-app and then navigate.
* Uses the switch in place of hardNavigate on four call sites.
* Keeps the emit-time integration on queued Glean events.
* Stops a superseded App session check from writing state.

Closes FXA-14791
