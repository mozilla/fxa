Description
## Because

- Nothing in the monorepo imports `bn.js` anymore. Its only consumer was the legacy BrowserID support document at `GET /.well-known/browserid`, which rendered the base64 RSA `n` and `e` values as decimal strings.
- Commit c80edbb43b removed that route and the import, but the root `package.json` kept the dependency, the `@types/bn.js` devDependency, and a `resolutions` pin.

## This pull request

- Removes `bn.js` from root `dependencies` and `@types/bn.js` from `devDependencies`.
- Removes the `bn.js` entry from `resolutions`.
- Regenerates `yarn.lock`.
