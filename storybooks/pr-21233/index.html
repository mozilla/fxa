Summary
fix(settings): Fix race creating pairing channel
Description
Because:

* React StrictMode double-fires the ScanQR mount effect in local dev,
  so createChannel() is called again while the first socket is still
  opening.
* The second call saw a channel with no id yet and could never build a
  QR code, leaving the page stuck.

This commit:

* Tracks the pending create in `_createChannelPromise` and returns it to
  any caller that arrives before it settles.
* Clears the pending promise once the create resolves or rejects.
* Adds tests for the shared-create path and for every concurrent caller
  rejecting when the create fails.

Closes #FXA-14543
