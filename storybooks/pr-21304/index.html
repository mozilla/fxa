feat(admin-panel): add Storybook and component stories
Description
## Because

- The admin panel had no Storybook, so there was no way to view its components and pages without a running admin server.

## This pull request

- Adds Storybook 8 (`@storybook/react-webpack5`) to `fxa-admin-panel`. The `.storybook/` config reuses `fxa-react/configs/storybooks`.
- Adds a preview decorator with `MemoryRouter`, `UserContext` (AdminProd group) and `GuardContext`.
- Adds stories for every component and page. Page stories stub `adminApi` through `src/lib/storybook.ts`.
- Adds `mocks.tsx` files with fake data for the pages that need it.
- Adds `storybook` (port 6011) and `build-storybook` scripts, plus an nx `build-storybook` target, so the existing deploy-storybooks workflow picks the package up.
- Sets `dependsOn: []` on the nx `build-storybook` target instead of `^build`. The CI Storybook job no longer builds `fxa-admin-server` and the payments libraries, whose Glean tasks raced on a shared `.venv` and failed.
