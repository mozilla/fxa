## Because

- Self-hosted `fxa-auth-server` did not start. typedi threw `SyntaxError: Unexpected identifier 'Object'` while `CMSHandler` resolved the CMS managers.
- The two CMS configuration managers annotated the injected logger with the winston `Logger` type. The seven other `LOGGER_PROVIDER` injection sites use `LoggerService`.

## This pull request

- Injects `LoggerService` from `@nestjs/common` in `default-configuration.manager.ts` and `relying-party-configuration.manager.ts`.
- Removes the unused `import type { Logger } from '@fxa/shared/log'` from both files. `LOGGER_PROVIDER` stays.
